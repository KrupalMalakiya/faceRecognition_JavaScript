# Contributing to FaceMatch JS

Thank you for your interest in contributing to **FaceMatch JS**! We welcome bug reports, feature proposals, documentation improvements, and pull requests.

## How Can I Contribute?

### 1. Reporting Bugs
* Search existing [Issues](https://github.com/KrupalMalakiya/faceRecognition_JavaScript/issues) to see if the problem has already been reported.
* If not, create a new issue including:
  * A clear, descriptive title.
  * Your operating system and browser version (e.g. Chrome 120, Firefox 122).
  * Steps to reproduce the bug.
  * Console error messages or screenshots if applicable.

### 2. Suggesting Enhancements
* Open an issue with the prefix `[Feature Request]`.
* Describe why the feature would be beneficial and how you envision it working.

### 3. Pull Requests
1. Fork the repository.
2. Create a new branch: `git checkout -b feature/your-feature-name`.
3. Make your improvements.
4. Test locally using a local web server (e.g., `npm start` or VS Code Live Server).
5. Commit your changes: `git commit -m "Add feature: your feature description"`.
6. Push to your fork: `git push origin feature/your-feature-name`.
7. Open a Pull Request against the `master` branch.

## Code Style & Guidelines
* Keep code modular, well-commented, and free of unnecessary dependencies.
* Ensure all model and image paths remain relative (`./models`, `./images`) so GitHub Pages compatibility is preserved.
* Test across multiple browsers (Chrome, Firefox, Safari/Edge) before submitting PRs.
